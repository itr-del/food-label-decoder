# 🍽️ Food Label Decoder

> **配料表是说明书，不是判决书。** 把化学名翻译成人话，把营销话术还原成事实。

普通人面对配料表，两个极端：要么看到一长串化学名就"不敢吃"，要么被"0 蔗糖""无添加"忽悠。本项目提供一套**4 层递进框架**，帮你理性判断、给家人挑对食品。

## 🚀 三步看懂配料表（极速版）

普通人只需记住这三步，覆盖 80% 判断场景：

```
Step 1：看前 2 项配料 → 判断产品本质（糖水？乳饮料？调味？）
Step 2：数糖种类     → 出现 ≥2 种糖类 → 减分
Step 3：找反式脂肪关键词 → "氢化""精炼植物油""代可可脂" → 警惕
```

进阶判断：调阅 [`references/`](./references/) 三个参考文档。

## ⚖️ 立场声明

- **不追求"零添加"**：那是营销概念，不是健康标准
- **不看名字化学不化学**：看它属于 4 类的哪一类 + 用量大概是多少
- **配料长 ≠ 不健康**：25 项的酸奶可能比 6 项的茶饮料更干净
- **不制造焦虑**：核心立场是"更安心地选，不是更焦虑地避"

- **WHO 2024** 代糖使用建议
- **中国营养学会** 居民膳食指南
