# 食品添加剂分级清单

按风险等级和使用频率分级。所有判断基于现行 GB 2760《食品安全国家标准 食品添加剂使用标准》和最新研究进展。

---

## 一、🟢 必含类（无害、必要）

这些添加剂在现代食品工业中几乎不可替代，看到不需要紧张。

| 类别 | 例子 | 说明 |
|---|---|---|
| 酸度调节剂 | 柠檬酸、碳酸氢钠、磷酸、乳酸 | 调风味、防变质，ADI 不限 |
| 抗氧化剂（天然） | 抗坏血酸、茶多酚、迷迭香提取物 | 防止油脂氧化，天然来源 |
| 增稠剂 | 黄原胶、瓜尔豆胶、果胶、明胶、琼脂 | 改善质构，无安全争议 |
| 乳化剂 | 单双甘油酯、硬脂酰乳酸钠、磷脂 | 稳定乳液，工艺必需 |
| 防腐剂 | 山梨酸钾、苯甲酸钠、丙酸钙 | 在 GB 限量内安全性有保障 |
| 防结剂 | 二氧化硅 | 奶粉/食盐防结块，ADI 高 |
| 增味剂 | 谷氨酸钠、酵母抽提物 | 增鲜 |

---

## 二、🟡 慎用类（特定人群需注意）

这些添加剂在大部分人群中安全，但特定人群（儿童、孕妇、过敏体质）需要关注。

| 添加剂 | 关注人群 | 关注点 |
|---|---|---|
| **代糖——阿斯巴甜** | 苯丙酮尿症患者（PKU） | 必需禁用，含苯丙氨酸 |
| **代糖——三氯蔗糖、安赛蜜、甜蜜素** | 大量长期摄入者 | WHO 2024 建议：不要为"健康"目的主动用代糖 |
| **代糖——糖醇类**（木糖醇、麦芽糖醇、赤藓糖醇） | 部分人 | 过量可能腹泻；2023 年研究提示赤藓糖醇可能增加心血管风险（待证实） |
| **合成着色剂**（诱惑红、柠檬黄、亮蓝等） | 儿童 | 部分研究提示可能加重多动；多个国家要求标注"可能影响儿童注意力"警示 |
| **亚硫酸盐** | 哮喘患者 | 可能诱发哮喘反应 |
| **咖啡因** | 儿童、孕妇、咖啡因敏感者 | 儿童不推荐常规摄入；孕妇限量 200 mg/天 |
| **高倍代糖混合物** | 所有人 | 长期影响研究不充分，建议偶尔使用 |
| **卡拉胶（降解型）** | 部分研究 | 食品级卡拉胶安全，降解型卡拉胶在小鼠实验中显示炎症反应（无食品使用） |
| **BHA / BHT**（合成抗氧化剂） | 所有人 | 动物实验有致癌争议，含量极低但建议减少摄入 |

**判定原则**：如果孩子每天大量食用（每日摄入量接近 ADI 边界），才需要规避；偶尔少量无需紧张。

## 三、🔴 避用类（条件性或争议较大）

### 1. 反式脂肪来源

| 来源 | 状态 | 说明 |
|---|---|---|
| **氢化植物油**（部分氢化） | **应避免** | WHO 目标 2025 全球禁用人造反式脂肪 |
| **精炼植物油**（高温处理） | 限制 | 高温精炼产生反式脂肪 |
| **人造黄油（margarine）/ 起酥油 / 代可可脂** | 警惕 | 通常含反式脂肪，看营养成分表"反式脂肪"项目 |
| 营养成分表反式脂肪 > 0 | 警惕 | 即便标 0 也可能有 < 0.5 g/100 g（标注豁免范围） |

**注意**：我国 2013 年起强制标注反式脂肪，但允许 < 0.5 g/100 g 标为 0。配料表出现"氢化""精炼植物油"应警惕。

### 2. 真正该警惕的添加糖

| 名称 | 陷阱 |
|---|---|
| 蔗糖、白砂糖 | 一目了然，但容易低估总量 |
| 果葡糖浆 | 高果糖玉米糖浆，代谢问题较多，建议避用 |
| 麦芽糖糖 | 升糖速度快 |
| 浓缩果汁、果葡糖浆 | 也是糖，但有"健康"伪装 |
| 蜂蜜 | 也是糖，但常被宣传为"天然健康" |

**关键判断**：配料表中糖类出现在前 3 位 → **该产品本质上是甜食/糖水**，无论宣传如何。

### 3. 已被禁/限用的添加剂

| 添加剂 | 现状 | 说明 |
|---|---|---|
| **脱氢乙酸钠** | 2024 新版 GB 禁用于多类食品 | 老版允许，新版收紧 |
| **苏丹红** | 完全禁用 | 工业染料，不是食品添加剂 |
| **三聚氰胺** | 完全禁用 | 工业原料 |
| **甲醛** / **吊白块** | 完全禁用 | 工业用途 |
| **硼砂 / 硼酸** | 完全禁用 | 工业用途 |
| **工业明胶**（用皮革下脚料熬制） | 完全禁用 | 与食用明胶的区别 |
| **瘦肉精（克伦特罗）** | 完全禁用 | 不属于食品添加剂，但常见违规 |

## 四、🔵 特殊情境关注清单

### 儿童零食
- 高糖（如果葡糖浆、麦芽糖在前 3 位）→ 警惕
- 反式脂肪（氢化植物油）→ 警惕
- 合成着色剂（诱惑红等）→ 优选无着色剂版本
- 重口味调味料（味精+大量盐+糖+辣）→ 警惕

### 烘焙食品
- 氢化植物油（植物黄油、人造奶油）→ 反式脂肪风险
- 高糖（蛋糕、饼干普遍）
- 复杂乳化剂组合（工艺需要）

### 乳制品
- 复原乳/还原乳 vs 生牛乳——配料表前 2 位判断
- 增稠剂（果胶、明胶）——工艺需要
- 甜味乳饮料 vs 发酵乳——看产品类别

### 饮料
- "0 蔗糖"≠"0 糖"——看是否有代糖
- "无添加防腐剂"——可能靠高糖/高酸/灌装工艺
- 茶饮料的"茶味"——香精 vs 真茶萃取

### 调味品
- 酱油——看氨基酸态氮（越高鲜味越足）和钠
- 鸡精——看是否含 MSG、I+G 等
- 蚝油——看蚝汁含量（配料表前 3 位）

## 五、家长快速决策树

给孩子选食品，按这个顺序判断：

```
1. 看前 2 项配料
   → 糖在前 3 位 → 不推荐常规食用
   → 反式脂肪（氢化植物油）→ 不推荐
   → 钠 NRV > 20% → 限量
2. 数添加糖种类
   → 出现 3 种以上糖类 → 警惕
3. 检查合成添加剂
   → 多种合成着色剂 → 优先无着色剂版本
4. 看营养成分表
   → 反式脂肪 > 0（即使标 0 也要看配料表）→ 警惕
   → 钠 > 400 mg / 100 g → 限量
5. 综合判断
   → 配料表短 + 天然成分为主 + 营养成分表干净 = 优
   → 配料表长 + 多糖多油 + 多种合成添加剂 = 谨慎
```

**不要追求"零添加"**，那是营销概念。追求的是"配料表反映真实成分 + 无明显风险项 + 营养成分表合理"。
