# 常用食品配料化学名还原词典

解读配料表时遇到陌生化学名，先来这里查。词典按"功能分类"组织，而不是按字母——读者关心的是"这个东西干嘛用"，不是"它叫什么"。

---

## 一、酸度调节剂 / pH 调节剂

| 化学名 | 日常身份 | 用途 |
|---|---|---|
| 碳酸氢钠（小苏打） | 厨房里做馒头用的 | 调节 pH、去涩、护色、护香 |
| 柠檬酸 | 柑橘类水果天然含有的酸 | 调酸味、防腐、抗氧化协同 |
| 柠檬酸钠 | 柠檬酸的钠盐 | 缓冲酸味、改善口感 |
| 磷酸 | 碳酸饮料里的酸 | 调酸味 |
| 乳酸 | 酸奶里的酸 | 调酸味、防腐 |
| 酒石酸 | 葡萄里的酸 | 调酸味、稳定剂 |
| 苹果酸 | 苹果里的酸 | 调酸味 |
| 抗坏血酸（维生素 C） | 维生素 | 抗氧化、防变色 |
| 异抗坏血酸（D-异抗坏血酸） | 维生素 C 的同分异构体 | 抗氧化（抗氧化能力同 VC，便宜） |
| 乙酸（醋酸） | 食醋主要成分 | 调酸味、防腐 |

**关键判断**：所有酸度调节剂 GB 2760 都允许使用，且 ADI 不限或极高。属于"看到不用慌"。

## 二、防腐剂

| 化学名 | 日常身份 | 备注 |
|---|---|---|
| 苯甲酸钠 | 最常见防腐剂之一 | 相对安全，酸性环境效果好 |
| 山梨酸钾 | 最常见防腐剂之一 | 比苯甲酸钠更安全，常用于面包、酱料 |
| 脱氢乙酸钠 | 防腐剂 | 2024 年新版 GB 已禁用或限用，需注意 |
| 丙酸钙 | 防腐剂 | 常用于面包、糕点防霉 |
| 亚硫酸盐（亚硫酸钠、二氧化硫） | 防腐/漂白剂 | 蜜饯、果干里多；哮喘患者慎用 |

**关键判断**：现代食品工艺下，"完全不含防腐剂"≠"更健康"（可能通过高糖/高盐/真空包装替代）。看到防腐剂不一定要恐慌。

## 三、甜味剂

| 化学名 | 日常身份 | 备注 |
|---|---|---|
| 蔗糖素（三氯蔗糖） | 代糖 | 甜度 600 倍蔗糖，0 热量 |
| 安赛蜜（乙酰磺胺酸钾） | 代糖 | 甜度 200 倍，常和阿斯巴甜复配 |
| 阿斯巴甜 | 代糖 | 甜度 200 倍，苯丙酮尿症患者禁用；2023 年 WHO 将其列为"可能致癌"（但每日安全摄入量 40 mg/kg 体重） |
| 甜蜜素（环己基氨基磺酸钠） | 代糖 | 中国允许，美国禁用 |
| 糖精钠 | 代糖 | 最早的代糖，甜度 300 倍 |
| 赤藓糖醇 | 天然代糖 | 近几年爆火，几乎无副作用 |
| 木糖醇 | 天然代糖 | 对牙齿友好 |
| 麦芽糖醇 | 糖醇类 | 部分人有腹泻反应 |
| 果葡糖浆 | 不是代糖，是真糖 | 高果糖玉米糖浆，代谢问题较多 |
| 结晶果糖 | 真糖 | 比蔗糖升糖指数低但仍是糖 |

**关键判断**：代糖不等于"健康"。WHO 2024 建议：**不要为了"健康"主动用代糖控糖**。但作为"偶尔替代含糖饮料"的方案，仍优于传统含糖饮料。

---

## 四、增稠剂 / 稳定剂 / 乳化剂

| 化学名 | 日常身份 | 用途 |
|---|---|---|
| 黄原胶 | 微生物发酵产物 | 增稠、稳定，沙拉酱里也有 |
| 瓜尔豆胶 | 豆科植物提取 | 增稠 |
| 卡拉胶 | 海藻提取 | 增稠、乳化 |
| 果胶 | 水果里天然存在 | 果酱增稠 |
| 明胶 | 动物骨皮提取 | 增稠、稳定 |
| 琼脂 | 海藻提取 | 增稠、做果冻 |
| 羧甲基纤维素钠（CMC-Na） | 纤维素衍生物 | 增稠、稳定，乳制品常用 |
| 三聚磷酸钠 | 磷酸盐类 | 保水、乳化 |
| 硬脂酰乳酸钠 | 乳化剂 | 改善口感 |
| 单硬脂酸甘油酯 | 乳化剂 | 面包、糕点抗老化 |
| 双乙酰酒石酸单双甘油酯 | 乳化剂 | 烘焙 |

**关键判断**：增稠剂/乳化剂几乎都是"工艺必需"，用来稳定乳液、悬浮、防沉淀。看到不需要紧张。

## 五、抗氧化剂

| 化学名 | 日常身份 | 用途 |
|---|---|---|
| 抗坏血酸钠 | 维生素 C 钠盐 | 防止油脂氧化 |
| 茶多酚（儿茶素） | 茶叶提取物 | 天然抗氧化 |
| 迷迭香提取物 | 香草提取物 | 天然抗氧化 |
| TBHQ（特丁基对苯二酚） | 合成抗氧化剂 | 防止油脂氧化，有争议 |
| BHA / BHT | 合成抗氧化剂 | 油脂防腐，动物实验有致癌争议 |

**关键判断**：天然抗氧化剂（茶多酚、迷迭香）> 合成抗氧化剂（BHA/BHT/TBHQ）。但含量都极低，不用过度恐慌。

---

## 六、着色剂

| 化学名 | 日常身份 | 备注 |
|---|---|---|
| 焦糖色 | 最常见着色剂 | 天然/加氨法两种工艺，后者可能含 4-MEI（动物实验有争议） |
| β-胡萝卜素 | 胡萝卜里的色素 | 天然色素 |
| 姜黄素 | 姜黄里的色素 | 天然色素 |
| 胭脂虫红 | 虫子提取的红色素 | 天然，素食者不用 |
| 诱惑红 / 柠檬黄 / 亮蓝 | 合成着色剂 | 部分儿童可能引起多动；多个国家已要求标注警示 |

**关键判断**：能不用就最干净。但合成着色剂在 GB 用量下安全性没问题，主要争议在儿童行为影响。

---

## 七、增味剂

| 化学名 | 日常身份 | 用途 |
|---|---|---|
| 谷氨酸钠（味精 MSG） | 调味品 | 增鲜 |
| 5'-呈味核苷酸二钠（I+G） | 增鲜剂 | 常和味精复配，鲜度叠加 |
| 酵母抽提物 | 酵母提取 | 天然增鲜 |

**关键判断**：味精无害早已被科学界确认。I+G 复配鲜味剂在方便面调料、酱油里普遍使用。

---

## 八、防结剂 / 抗结块剂

| 化学名 | 日常身份 | 用途 |
|---|---|---|
| 二氧化硅 | 沙子成分 | 防止粉末结块（食盐、奶粉） |

**关键判断**：极常见，无安全争议。

---

## 解读技巧速记

遇到陌生化学名，按这个顺序排查：

1. **先看属于哪一类**——酸度调节/防腐/甜味/增稠/乳化/抗氧化/着色/增味
2. **再查日常身份**——上面 8 大类里基本都覆盖
3. **最后看是否在添加剂分级清单里**——见 `additive-watchlist.md`

记住一句口诀：**"名字化学 ≠ 用量大；功能重要 ≠ 不安全"**。
